## Навигация и метаданные

На всех страницах используются одинаковые шапка, меню и подвал. Текущая страница
отмечена атрибутом `aria-current="page"`. На внутренних страницах есть хлебные
крошки «Главная / Каталог» и «Главная / Контакты».

Меню содержит переходы между страницами и ссылки на разделы главной:

- `index.html#advantages` — преимущества;
- `index.html#popular` — популярные товары и кнопки заказа;
- `index.html#contacts` — блок обратной связи в подвале.

У каждой страницы уникальные `title` и `meta name="description"`.
Для якорей добавлены плавная прокрутка и выделение через `:target`.
При настройке уменьшения движения в системе плавная прокрутка отключается.

## Flexbox и CSS Grid

В проекте применены современные инструменты CSS-раскладки:

- Flexbox используется для расположения логотипа и навигации в шапке сайта;
- Flexbox используется для горизонтального расположения пунктов меню;
- ссылки меню имеют увеличенную кликабельную область и фон при наведении;
- Flexbox используется внутри карточек: элементы идут в столбец, а `margin-top: auto` выравнивает кнопки по нижнему краю;
- CSS Grid используется для расположения карточек товаров в три колонки;
- CSS Grid используется для каталога: `grid-template-columns: 260px minmax(0, 1fr)` задаёт боковую колонку и оставшееся пространство для товаров;
- именованные области `filters` и `products` задаются через `grid-template-areas` и `grid-area`;
- форма фильтров размещает группы полей через Grid;
- свойство `gap` используется для задания расстояния между элементами.

Форма фильтров содержит категории «Все товары», «Популярные», «Новинки» и диапазон
цены. В практической работе 6 реализованы разметка и оформление формы: кнопка
«Применить» отправляет GET-параметры на страницу каталога, но список товаров
пока не фильтруется. Полноценная адаптивная вёрстка остаётся для следующих работ.

## БЭМ-именование

Для компонента карточки товара используется базовое БЭМ-именование классов:

- `product-card` — блок карточки товара;
- `product-card__title` — название товара;
- `product-card__description` — описание товара;
- `product-card__price` — цена товара;
- `product-card__button` — кнопка заказа.
